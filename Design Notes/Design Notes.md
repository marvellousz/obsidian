
# UI / Product Design Process

The design process usually follows three stages:

1. **Wireframe**
    
2. **Mockup**
    
3. **Design (Final UI)**
    

---

# 1. Wireframe

A **wireframe** is the basic structural layout of a product.

It focuses only on:

- Layout
    
- Structure
    
- Content placement
    
- User flow
    

There are **no colors, fonts, or visual styling**.

Think of it as a **blueprint of the interface**.

### Purpose

- Plan the structure
    
- Decide component placement
    
- Understand user navigation
    
- Quickly iterate on ideas
    

### Example Elements

- Boxes for images
    
- Placeholder text
    
- Navigation layout
    
- Button positions
    

---

# 2. Mockup

A **mockup** is a **visual representation** of the interface.

It adds **visual design elements** to the wireframe.

Includes:

- Colors
    
- Typography
    
- Icons
    
- Spacing
    
- Branding
    
- UI components
    

But it is still **static** (not interactive).

### Purpose

- Show how the product will look
    
- Validate visual style
    
- Present to stakeholders
    
- Align with branding
    

---

# 3. Design (Final UI)

The **final design** is the polished and production-ready UI.

This stage includes:

- Pixel-perfect UI
    
- Component system
    
- Design tokens
    
- Responsive layouts
    
- Interaction states
    

Often includes **interactive prototypes**.

### Purpose

- Prepare for development
    
- Ensure design consistency
    
- Define component behavior
    

---

# Quick Summary

|Stage|Focus|Visual Detail|Interaction|
|---|---|---|---|
|Wireframe|Structure|Low|No|
|Mockup|Appearance|Medium–High|No|
|Design|Final product UI|High|Yes|
